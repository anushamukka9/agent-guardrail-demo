What MCP servers do

Model Context Protocol servers give AI assistants a standard way to reach outside tools. Instead of every assistant reimplementing database lookups, file search, or ticket queries, the protocol defines one JSON-RPC surface that any host can speak to any server.

Each server advertises three things: tools the model may call, resources it may read, and prompt templates it may use. A file search server might expose a single tool, while a customer support server might expose a dozen.

The security story is still being written. A server decides what its tools can touch, but the host decides which servers to trust. When a model calls a tool, the arguments cross a trust boundary, and anything the tool returns should be treated as untrusted data, not as orders.

That last point is the one this demo is about. Tool output is data. The moment an agent treats it as instructions, whoever wrote the tool output is driving.
